# Unc.Fund

Frontier-tech VC fund writing 3- and 4-figure checks into pre-pre-seed, pre-seed and seed companies in Blockchain, AI, Software and Robotics.

Started as a joke. Now it has a domain (unc.fund), an X account, and a plan. Structured as a single-member LLC to begin with.

## This repo

Standalone project. Nothing here is shared with any other project.

| Path | What it is |

| `docs/01-vc-research.md` | Due diligence on other VC firms: websites, tech stacks, marketing, and the comedic ones |
| `docs/02-launch-todo.md` | The full launch checklist: handles, legal, brand, website, content |
| `docs/03-brand.md` | Brand direction: the animated Unc mascot, voice, palette, logo and merch ideas |
| `docs/04-website-spec.md` | Site map, stack recommendation, page-by-page copy draft |
